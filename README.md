# Pletina

Reproductor de MP3 y MP4 para el móvil, sin anuncios y sin conexión.

- Biblioteca, listas de reproducción y cola (se reordenan arrastrando)
- Vídeo arriba y lista debajo; pantalla completa al girar el móvil
- Vista «Pletina» con vúmetros y forma de onda reales
- Los archivos se guardan solo en el dispositivo (IndexedDB)

Abrir: https://smithaldana.github.io/pletina/ → en Chrome, menú ⋮ → «Instalar aplicación».
